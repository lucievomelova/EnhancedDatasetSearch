# Metadata
Každý dataset obsahuje metadata, která poskytují informace o struktuře a obsahu dat. Metadata zahrnují:
- Název datasetu
- Popis datasetu
- URL
- Poskytovatel - organizace, která dataset poskytuje
- Kategorie datasetu - kategorizace datasetu podle předdefinovaných kategorií
- Klíčová slova - důležitá klíčová slova související s obsahem datasetu, která usnadňují vyhledávání a kategorizaci dat
- Témata - hlavní témata, která dataset pokrývá
- Časové pokrytí - časové období, které dataset pokrývá (např. konkrétní rok)
- Geografické pokrytí - související geografické území (kraj, město, okres)

## Kategorie
Každý dataset je zařazen do jedné nebo více kategorií z tohoto seznamu:
- Zemědělství, rybolov, lesnictví a výživa
- Vzdělávání, kultura a sport
- Životní prostředí
- Energie
- Doprava
- Věda a technika
- Hospodářství a finance
- Populace a společnost
- Zdraví
- Vláda a veřejný sektor
- Regiony a města
- Spravedlnost, právní systém a veřejná bezpečnost
- Mezinárodní otázky
- Jiné
